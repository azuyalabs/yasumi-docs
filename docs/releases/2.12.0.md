# Yasumi 2.12.0 Release Notes

_Released on September 30, 2026_

Yasumi 2.12 is here! In this new release of Yasumi we welcome Colombia and Kenya to the list of providers, increasing the list of countries to 49. Next to new providers, numerous fixes and improvements have made it into this release since the [last](https://github.com/azuyalabs/yasumi/releases/tag/2.11.0) one, so it is definitely worthwhile to upgrade. 

In a recent [discussion](https://github.com/azuyalabs/yasumi/discussions/428), it become evident that it wasn&#039;t really clear when a new release of Yasumi was to be expected. Up until not too long ago, I made a release whenever a useful set of changes had accumulated, which over time made the release history look somewhat arbitrary. 

To make it easier for users to understand when a next release is to be expected, a [Release Policy](https://github.com/azuyalabs/yasumi/blob/develop/RELEASE.md) has now been added to the project. At a minimum, two releases per year will be made: one in March (Spring Release) and one in September (Autumn Release). I hope it makes the release cadence a little more predictable.
